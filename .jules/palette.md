## 2026-05-03 - Cross-Platform Input Support for Minigames
**Learning:** Hardcoding interactions to single platform inputs (like keyboard Spacebar) excludes mobile and console users.
**Action:** Always implement multiple input bindings (Keyboard, Touch/Mouse, Gamepad) using `UserInputService` to ensure cross-platform accessibility.
